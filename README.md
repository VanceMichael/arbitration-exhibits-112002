# 联运争议证据的分层取件和封存的演练来源

这里提供独立来源的本地合成记录，与实际单位、个人和线上业务无关。

## 本地运行

使用 Node.js 22.23.4。只使用 Node.js 自带的运行库。

执行 `npm test` 检查合成来源的接口。执行 `npm start` 启动来源，默认监听 `127.0.0.1:4100`，可通过环境变量 `PORT` 调整端口。访问根路径可看到来源名和当前回放阶段。

## 接口资料

| GET 路由 | 来源约定 |
| --- | --- |
| `/source/carriers` | declaration 只关联一个运程交接。content 是声明的原件摘要；当事人及案卷双方的权限独立。 |
| `/source/depot` | pieces 按列出的次序拼接原始字节后核对摘要。withdraw 以 entrance 为作用域。 |
| `/source/service` | served 关联案卷、当事人、声明版本和原文摘要。sealed 是书记员封卷时的原有状态。 |

查询参数 `offset` 是从零开始的页偏移，`limit` 默认 3，取值 1 至 100。响应中的 `records` 含 `record` 来源记录键、`availableFrom` 首次出现的回放阶段、`kind` 记录类型、`payload` 业务字段。来源记录键与业务身份分别定义。`next` 为下一页偏移，末页为 `null`。回放阶段中的记录按到达顺序可查。

控制员通过 `POST /control?stage=2` 切换到第 2 阶段，服务会保留更早已可查的记录。每次换阶段后按根路径返回的 `stage` 确认切换成功。原件请求为 `GET /original/文件名`，带托管端的 `entrance`、案卷的 `case` 和查询所针对的本地时刻 `at`（HH:mm）。案卷或取件号不符、失效、撤下会返回 403，只有取件号目录列出的分段可领取。原件文件和摘要记录在 `originals/` 与来源索引。

## 仲裁台账客户端（`arb.mjs`，仅用 Node 自带运行库）

客户端按回放阶段依次接入三个来源，把事实写入只追加台账 `work-data/ledger.jsonl`，核验通过的原件按内容摘要存入 `work-data/custody/`。来源记录以 `来源:记录键` 去重，重复同步不产生重复事实；撤下、补领、修订都只以新事件表达，任何历史事件都不被改写或替换。

关键判定原则：

- **内容身份而非入口身份**：分段按取件号列出的次序拼接后核 sha256；公布目录标题或取件成功都不证明内容，摘要不符只记 `custody_failed`，绝不入管。同内容可复用已获准保管的原件（`custody_reused`），但不扩大另一案卷或当事人的阅览范围。
- **授权作用域隔离**：撤下以 `entrance` 为作用域。撤下事件入账时固化 `withdrawal_impact` 快照——哪些待送关系停止补领、哪些已交材料仅历史可查、哪些其他案卷仍有同内容的独立授权。
- **修订独立送阅**：`replaces` 声明（如 DEC79-R2）是不同内容的新版本，保留版本链与差异记录，回执按声明版本隔离，晚到的原卷附件回执不会被误算成修订件收悉。
- **封存可复查**：封卷时核验 `known` 回执真实存在、`outstanding` 确未收悉，卷外关系单独标记，缺件边界不被后续事件改写。

### 命令

先 `npm start` 启动来源，再执行（可用 `--source`、`--work` 覆盖默认地址与台账目录，`--json` 输出机读结果）：

| 命令 | 用途 |
| --- | --- |
| `node arb.mjs sync` | 分阶段回放全部来源，取件、拼接核摘要、固化撤下快照与封存核验 |
| `node arb.mjs cases` | 列出台账中的案卷号 |
| `node arb.mjs case <案卷号>` | 显式分三层查看：原件、关联声明、后续修订；并逐当事人给出补领/补送/退请说明/已收悉 |
| `node arb.mjs impact <入口号>` | 对照撤下入账时的历史快照与按当前时刻重算的影响 |
| `node arb.mjs seals` | 查看封存卷宗的已收悉范围、缺件边界与卷外关系 |
| `node arb.mjs events` | 按序号查看只追加事件流 |

处置含义：**补领**＝授权入口仍有效但原件未到齐；**补送**＝原件已核验在管、当事人尚未收悉；**退请说明**＝无有效取件号且无在管原件（授权链断裂）或回执摘要与声明不一致；**已收悉**＝已有内容一致的回执。
